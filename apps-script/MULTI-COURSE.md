# รองรับหลายวิชาต่อเลขประจำตัวนักเรียน

เผยแพร่ในโครงการ Apps Script ที่ผูกกับไฟล์ ปพ.5-69 วันที่ 16 กันยายน 2026 (เว็บแอปเวอร์ชัน 9) โดยคง URL และสิทธิ์เดิม

## แหล่งข้อมูล

- อ่านทุกแถวใน `❇️03-กรอกคะแนน` ตั้งแต่แถว 6: เลขประจำตัว B, ห้อง F, รหัสวิชา AI
- ใช้รหัสวิชาและห้องเป็นตัวแยกรายวิชาของนักเรียน ไม่หยุดเมื่อพบเลขประจำตัวครั้งแรก
- อ่านเวลาเรียนจาก `❇️02-เช็คชื่อ` โดยจับคู่เลขประจำตัวและชื่อห้องแบบตรงตัว เช่น `4/2-พฐ` ไม่ใช่ห้องเดียวกับ `4/2`
- ชื่อวิชาอ้างอิงตารางห้อง/วิชาใน `❇️00-ตั้งค่า` ช่วง B18:D31
- สิทธิ์ยังอ้างอิง `🔒LINE_Accounts` และต้องเป็น `active`
- ไม่ใช้ชีตเสริม `🤖LINE_รายวิชาเพิ่ม`

## โค้ดในโครงการจริง

`MultiCourseData.gs` เก็บชุดฟังก์ชันที่ต่อท้ายไฟล์ **LineScoreBot.gs** ในโครงการจริง ส่วน `MultiCourseApi.gs` ต่อท้าย **LineBotApi.gs** หลังฟังก์ชันเดิม เพื่อแทนที่การอ่านเฉพาะแถวแรกและเพิ่มการเลือกรายวิชา ห้ามวางก่อนฟังก์ชันเก่าที่ชื่อซ้ำ

- `verifyMultiCourse()` ตรวจจำนวนข้อมูลและเวลาเรียนโดยไม่แสดงข้อมูลส่วนบุคคล
- `syncDatabase()` ส่งข้อมูลนักเรียนพร้อมรายวิชาทั้งหมดไปฐานข้อมูลบอทเดิม
- เมื่อเปลี่ยนโค้ด API ให้เผยแพร่ **เวอร์ชันใหม่ของรายการเดิม** ไม่สร้าง URL ใหม่

## การใช้งาน

1. นักเรียนพิมพ์ `เช็กคะแนน`
2. ถ้ามีวิชาเดียว แสดงสรุปเหมือนเดิม ถ้ามีหลายวิชา แสดงปุ่มเลือกรายวิชา
3. เลือกวิชาแล้วพิมพ์ `รายละเอียดคะแนน` หรือ `เวลาเรียน` เพื่อดูวิชาที่เลือก
4. พิมพ์ `เช็กคะแนน` อีกครั้งเพื่อเลือกวิชาอื่น

ฝั่งบอทเก็บวิชาที่เลือกแยกตามครู บัญชี LINE และเลขประจำตัวนักเรียน ไม่เปลี่ยนสิทธิ์และไม่รวมคะแนนข้ามวิชา

ผลตรวจข้อมูลต้นทางขณะเผยแพร่: นักเรียน 227 คน, รายการวิชา 263 รายการ, นักเรียนที่มีมากกว่าหนึ่งวิชา 35 คน, รายการที่ไม่พบคู่เวลาเรียน 0 รายการ
